# Importer fixtures

Tests construct minimal upstream-shaped and portable records in temporary directories. Keeping
fixture values in the tests makes each malformed relationship and sprite expectation explicit; no
fixture is copied from the upstream repository.

`pre-evolution-learnset.json` is a minimal source-shaped resolver fixture. It proves that an absent
form entry can resolve through a pre-evolution without claiming that the pinned Champions tables
exercise that branch.

The six `m-a-*-item-text.json` fixtures pin every before/after transition in the sole approved
cross-revision Item-text compatibility set.
